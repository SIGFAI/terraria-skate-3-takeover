# Skate 3 Takeover

**Terraria** × Skate 3 · visual · idea by the team

Bring Skate 3 into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I put Skate 3 into Terraria: everyone rides a board, enemies bail in a tumble, and a mall cop gets the Hall of Meat.

## Install

Copy Sigf.tmod into Documents/My Games/Terraria/tModLoader/Mods, then enable it in tModLoader's Mods menu. Start a world and grab the Skate Deck to throw boards at the skater punks.
